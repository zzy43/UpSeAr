# B757/767 手册库（离线网页版）

把 6 本手册的 PDF 转成了一组纯静态网页：**一个手册一个文件夹，双击里面的 `index.html` 就能看**。
左边是章节目录（默认折叠，点 ▸ 逐级展开），右边是正文；支持搜索、折叠小节、调字号、亮暗模式、手机收起目录栏。
顶栏最左边那排简写（SOP / FCTM / AFM / FCOM1 / FCOM2 / OA）用来在各本手册之间互相跳。

> 不需要联网、不需要服务器、不需要 Node.js，`file://` 直接打开即可。
> 内容属公司内部资料，请只在内部学习/工作范围内使用。

---

## 一、目录结构

```
B757手册库/
├─ README.md                  ← 本说明
├─ 重新生成全部.cmd            ← 一键重新生成 6 本手册的全部章节（Windows 双击）
├─ pdf_to_sop.py              ← PDF → 网页数据 的转换脚本（核心）
│
├─ SOP/index.html             ← 标准操作程序 R05（7 章）
├─ 训练手册/index.html         ← 飞行机组训练手册（8 章）
├─ 飞行手册/index.html         ← B757-200ER 飞机飞行手册 R00-03（12 节）
├─ 操作手册V1/index.html       ← 飞行机组操作手册 V1 R02-10（5 章）
├─ 操作手册V2/index.html       ← 飞行机组操作手册 V2 R02-10（15 章）
├─ 运行手册/index.html         ← 运行手册 R05-04（19 章）
│   └─ （每本下面的 data/*.js 就是该手册各章的正文数据）
│
└─ （本包不含源 PDF —— 要重跑脚本时，把手册 PDF 拷回本文件夹即可，见第三节）
```

- **样式和交互脚本是共用的**：`SOP/css/sop.css` + `SOP/js/sop.js`。
  其余五本手册的 `index.html` 都引这两个文件（`../SOP/css/sop.css`、`../SOP/js/sop.js`），
  所以**改一次样式/交互，六本同时生效**；`SOP/` 这个文件夹别单独删掉或改名。
- 每个 `data/*.js` 只做一件事：`window.SOP_CHAPTERS.push({no, title, nav, html})`，
  用 `<script src>` 引进来（不用 `fetch`，所以 `file://` 下也能跑）。

## 三、重新生成正文（改了 PDF、或想调整转换规则时）

### 0. 先把源 PDF 放回本文件夹

**本包为了体积没带 PDF**（6 本加起来约 128 MB）；网页本身不需要 PDF，随便看。
只有要「重新生成正文」时才需要把 PDF 拷回本文件夹根目录。

拷回来时**文件名必须和脚本里写的一致**（在 `pdf_to_sop.py` 的 `MANUALS` 里），不能改名，否则脚本找不到：

```
YTO-01-27-2 B757&B767标准操作程序（R05-02试运行） (1).pdf     → sop
757&767 飞行机组训练手册.pdf                                    → train
YTO-01-04-2 B757-200ER飞机飞行手册 (R00-03）.pdf                → afm
YTO-01-05-02 B757-200 飞行机组操作手册 V1(R02-10）.pdf          → fcom1
YTO-01-05-02 B757-200 飞行机组操作手册 V2(R02-10）.pdf          → fcom2
Operations Manual（R05-04）.pdf                                 → oa
```

（注意两处容易错的括号：AFM 的 `(R00-03）` 是英文左括号 + 中文右括号，操作手册 V1/V2 是 `V1(R02-10）` 这种。）

### 1. 装依赖

需要 Python 3.10+ 和 `pypdf`：

```bat
python -m pip install pypdf
```

### 2. 生成

```bat
python pdf_to_sop.py sop 3          :: 重新生成 SOP 的第 3 章
python pdf_to_sop.py fcom2 1 5 9    :: 一次生成多章
python pdf_to_sop.py oa             :: 不给章号 = 只生成第 1 章
```

- 章号是**按书签顺序数的第几个**（不是书里的章号），写完会打印一章一行的小结：
  起止页、丢了多少页眉页脚、识别出多少张表格，以及最关键的
  **「完整性核对：源文 N 字 / 网页 N 字 → 一致(OK) / 有差异(DIFF)」**。
- 脚本会把整份小结同时写到同目录的 `_report.txt`（UTF-8），比看控制台可靠。
- 「有差异(DIFF)」不一定是丢内容：常见的是同一段文字在网页里被并成了一段（字数相同、只是行序不同），
  或者是页眉/运行章名被剔除。真丢内容的话差异明细里会看到成串的正文。

## 四、转换脚本干了什么（`pdf_to_sop.py`）

1. **分章分节**：读 PDF 书签（`reader.outline`）。默认认「第N章」；每本书可以在 `MANUALS` 里配
   `chapre`（正则）自定义，例如 AFM 认「第N 节/附录N/*补充手册*」，FCOM 认「L章/NP章/SP章/PI-/改装厂补充手册」或
   「数字+系统名」；`navfmt` 决定侧边栏里怎么显示。
2. **正文行**：用 `extract_text(extraction_mode="layout")` 拿带换行的文本，
   再用 `visitor_text` 拿每段文字的坐标和字体（用来认粗体小标题）。
3. **表格**：不信「两个空格 = 换列」这种猜法，而是读 PDF 里**真画出来的框线**
   （`re` / `m`+`l` 指令），用横线定行、竖线定列，缺一段线就是合并单元格 → `colspan` / `rowspan`；
   跨页断开的表会按页面位置自动接回同一张表。
4. **清理**：页眉、页脚、本章目录页、「有意空白/有意留白/有意留空」占位、清单里的点线行、
   与表格重复的碎渣行等，都按规则剔除（每本书可以再配 `droplines` / `droppage` / `zones`，见下）。
5. **图片**：一律不收录（手册里的图、示意图、原理图都没有）。

## 五、再加一本新手册

1. 在 `pdf_to_sop.py` 的 `MANUALS` 字典里加一行：

```python
"newbook": {"pdf": "新手册文件名.pdf",            # 放在本文件夹下
            "dir": "新手册",                      # 网页目录名（中文也行）
            "name": "手册全名 · 版本",
            # 下面这些按需加，不加就是默认行为：
            "chapre": r"^第\s*\d+\s*节",          # 自定义「什么算一章」（正则）
            "navfmt": "%(title)s",                # 侧边栏标题格式（%(title)s / %(no)s / %(sub)s）
            "zones": (4, 2),                      # 页顶 4 行 / 页底 2 行：重复出现的行第二次起丢掉（消页眉页脚）
            "droplines": (r"^\\s*页码\\s",),       # 额外的「见到就丢」的行（正则）
            "droppage": r"\\.TOC\\.|ModID"},       # 整页丢（目录页 / 有效页清单页）
```

2. 跑一次：`python pdf_to_sop.py newbook 1 2 3`（先跑一章看看对不对）。
3. 复制一个现成的阅读页当模板（比如 `运行手册/index.html`），改三处：
   `<title>`、`data/*.js` 的 `<script>` 列表、顶栏 `mnbar` 里那排简写。
4. 其余五本的顶栏 `mnbar` 里也补上这本的简写链接。

## 六、已知取舍

- 图片、部分纯图形页（只有图没有文字）是空的——PDF 里的图不抽取。
- 手册自己的目录页不收录（目录由网页根据书签自动生成），所以侧边栏目录可能比纸质目录更细或略少。
- 页眉页脚里的编号/日期、`D632N001-56YTW` 这类版权行一律剔除。
- 表格只按框线还原；用大段空格排版、但没画框线的「伪表格」会按普通文字处理。
- 顶栏那排简写里，当前这本是 `<span class="mn on">`（不可点、高亮），其余是可点的 `<a class="mn">`。
